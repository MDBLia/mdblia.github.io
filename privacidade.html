Política de privacidade

O Workspace MCP Britto é um app de uso pessoal. Ele é usado apenas pelo seu dono, com a conta Google dele.

Quais dados ele acessa

Eventos do Google Agenda, tarefas do Google Tasks e arquivos do Google Drive e do Planilhas Google da conta do dono, só quando o dono pede alguma ação ao seu assistente pessoal.

Como os dados são usados

Os dados servem apenas para criar, consultar e atualizar compromissos, lembretes e planilhas do próprio dono. Eles não são vendidos, compartilhados com terceiros nem usados para publicidade.

Onde ficam

O acesso roda num servidor doméstico do dono. As credenciais de acesso ficam guardadas só nesse servidor.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

Uso dos dados de APIs do Google: o app segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.
